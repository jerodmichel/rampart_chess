Flags in this folder are ALL from one single Wikimedia Commons category -
"Flags of extinct states": https://commons.wikimedia.org/wiki/Flags_of_extinct_states
- optimized with svgo. Most are public domain (simple geometric/historical
designs); some are CC-BY-SA and require attribution if redistributed
outside this app. Source file per code, for reference.

(A handful of Europe entries - Austria-Hungary, German Empire, Kingdom of
Italy, Grand Duchy of Lithuania, Duchy of Milan, Papal States, Prussia,
Serbia and Montenegro, Sweden-Norway, Ukrainian People's Republic - were
originally pulled from a DIFFERENT, related Commons category ("Flags of
former countries of Europe") in an earlier session, before this single-
source approach was settled on. Removed on 2026-09-13 to keep this list
matching exactly one canonical source rather than two overlapping ones -
see project_rampart_extinct_flags memory for the full story.)
